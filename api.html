API Reference

Complete documentation for the Zurai Hub Lua runtime API.

Overview

Zurai Hub exposes a global Zurai table the moment the loader executes. All submodules are lazy-loaded on first access — only the code you actually use gets fetched. The loader is delivered via loadstring(game:HttpGet(…))() and bootstraps the VM optimizer, environment detector, and polyfill layer before surfacing the public API. 

-- One-liner to bootstrap Zurai Hub
loadstring(game:HttpGet("https://zurai02.github.io/zurai-hub/loader-api.html"))()
Loader

The loader bootstrap sets up the environment, runs the 5-pass VM optimizer, and populates the global Zurai table.

fn Zurai.load(moduleId)
moduleId string Module identifier. One of: "esp", "aim", "move", "crypto"
returns module table or nil on fetch failure 
local esp = Zurai.load("esp")
esp.enable({ boxes = true, names = true })
fn Zurai.version()
returns string — semver, e.g. "3.3.0"
Net

HTTP utilities with built-in retry, fallback chains, and parallel batching.

Function Parameters Returns Description
Net.get(url) url: string string | nil HTTP GET with exponential backoff (3 retries, jitter). Returns body or nil.
Net.getWithFallback(urls) urls: string[] string | nil Iterates fallback URL list, returns first successful body.
Net.fetchBatch(urls, cb) urls: string[], cb: function void Parallel coroutine fan-out, 32 s timeout, fDone race guard. Calls cb(url, body) per result. 
-- Parallel fetch example
Zurai.Net.fetchBatch({
  "https://cdn1.example.com/mod.lua",
  "https://cdn2.example.com/mod.lua",
}, function(url, body)
  if body then loadstring(body)() end
end)
Env

Executor detection and compatibility layer management.

Property / FunctionTypeDescription
Env.executor string Detected executor name. One of: syn, krnl, fluxus, wave, oxygen, electron, unknown.
Env.sigCount number Number of positive signature matches found during the 32-sig scan.
Env.hasPolyfill boolean True if the polyfill layer was applied for missing globals.
Env.identify() → string Re-runs the signature scan and returns the executor name string.
VM

The 5-pass optimizer pipeline runs automatically at load time. These controls let you tune or re-run it manually.

PassIDEffect
1 — cfold"cfold"Constant folding: evaluates constant sub-expressions at compile time.
2 — dce"dce"Dead code elimination: removes unreachable branches.
3 — peep"peep"Peephole: replaces instruction sequences with shorter equivalents.
4 — jthread"jthread"JIT thread hints: marks hot loops for preferential scheduling.
5 — inline_moves"inline_moves"Inline move coalescing: collapses redundant register transfers.
 
-- Run optimizer with specific passes only
Zurai.VM.optimize({
  passes = { "cfold", "dce", "peep" },
  verbose = false,
})
Crypto

Cryptographic utilities for integrity checking and obfuscation. Based on XChaCha20-style keystream with xorshift32 seeding and SBox mixing.

FunctionParametersReturnsDescription
Crypto.xorKey(data, key) data: string, key: number string XOR each byte of data against the keystream derived from key.
Crypto.hash(data) data: string number XOR-fold hash of data. Used internally as _ICH_VAL integrity check.
Crypto.rand(min, max) min: number, max: number number Deterministic PRNG value in [min, max] from xorshift32 state.
ⓘ Crypto is automatically used by the anti-tamper integrity check at loader init. The _ICH_VAL guard will abort execution if the loader source has been modified.
Modules
MOD ESP

Box, skeleton, name, health overlays. Per-team color support. v2 rewrite with configurable render distance.

MOD Aimbot

Silent aim, configurable FOV circle, smoothing factor, bone targeting (head/torso), team-check filter.

MOD Movement

Fly mode, speed multiplier, noclip. Powered by BodyVelocity + BodyGyro. Toggle-safe cleanup on disable.

MOD Crypto

XChaCha20-style keystream, XOR encryption, integrity hash guard for anti-tamper protection. 

-- Load and configure the movement module
local move = Zurai.load("move")
move.fly({ speed = 80, enabled = true })
move.noclip(true)

-- Disable and clean up
move.disable()
Error Codes
CodeConstantMeaning
E001ERR_NET_FAILAll CDN fallbacks exhausted. Check network connectivity or try a different executor.
E002ERR_ICH_FAILIntegrity check failed. Loader source has been tampered with. Re-fetch the loader.
E003ERR_NO_EXECNo executor environment detected. Run inside a supported Roblox executor.
E004ERR_MOD_LOADModule fetch returned nil or failed to parse. Check moduleId spelling.
E005ERR_POLYFILLPolyfill could not shim a required global. Executor may be too outdated.
