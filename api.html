Zurai Hub API

Internal module surface exposed after the hub initialises. All symbols live under the _ZH global table injected into the executor environment.

Core Modules

Available Namespaces

_ZH.VM Virtual Machine
_ZH.VM.compile(src: string) → proto
Lex → parse → 5-pass optimise → return proto table.
_ZH.VM.run(proto, env?) → ...any
Interpret a compiled proto inside an optional environment table.
_ZH.VM.loadstring(src: string) → function
Convenience: compile + wrap as a callable closure.
_ZH.Net Network / Fetch Layer
_ZH.Net.get(url: string) → string?
GET with exponential backoff (initial 0.3 s, max 8 s, ±100 ms jitter, 4 retries).
_ZH.Net.getWithFallback(urls: {string}) → string?
Try each URL in order; return first successful response.
_ZH.Net.fetchBatch(names: {string}) → results
Parallel fetch with 32 s timeout and fDone race guard.
_ZH.Sec Security / Anti-Detection
_ZH.Sec.checkEnv() → nil
Scan 24 executor signatures; log detected APIs and executor name.
_ZH.Sec.antiTamper() → nil
Check for meta-hook injection, hookfunction API, and excess DescendantAdded connections.
_ZH.Sec.integrityHash → number
XOR fold of first 32 keystream bytes; non-zero means keystream is valid.
_ZH.Crypto XChaCha20-style PRNG
_ZH.Crypto.xs32(x: number) → number
xorshift32 PRNG step; seed is 0xDEAD_BEEF.
_ZH.Crypto.xe(data: {byte}) → {byte}
XOR-encrypt a byte table against the keystream.
_ZH.Crypto.xd(data: {byte}) → string
XOR-decrypt a byte table and return the plaintext string.
Quick Example

Usage Snippet

-- After Zurai Hub has loaded:
local zh = _ZH

-- Compile and run a string
local proto = zh.VM.compile("return 1 + 1")
local result = zh.VM.run(proto)
print(result) -- 2

-- Fetch with fallback
local src = zh.Net.getWithFallback({
    "https://cdn1.example.com/script.lua",
    "https://cdn2.example.com/script.lua",
})
if src then zh.VM.loadstring(src)() end

ⓘ You are viewing this in a browser. The API is only active inside a Roblox executor environment after the hub script executes.
